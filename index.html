Confidentialité & sécurité

Les protections utiles, expliquées simplement.

Stockage local

Une copie non chiffrée par mot de passe reste dans ce navigateur pour le mode hors ligne. Elle est séparée par compte. Sur un appareil partagé, protégez votre session et effacez les données du navigateur après usage.

Connexion HTTPS

Le site est servi via HTTPS : vos données sont chiffrées pendant leur transfert.

Synchronisation de compte (optionnelle)

Lorsque vous vous connectez, votre tableur est synchronisé avec votre compte Meuniance via une connexion chiffrée. Les données sont hébergées par Supabase, dans l’Union européenne (Irlande).

Pas de publicité ni de suivi

Ce site ne contient aucun traqueur, cookie publicitaire ni outil d’analyse tiers. Nous ne vendons pas vos données ; elles sont hébergées par Supabase et Vercel et, pour les paiements, traitées par Stripe.

Ce qui est enregistré

Votre adresse e-mail, le contenu de votre tableur (libellés, montants, dates), vos objectifs et les partages accordés. Votre mot de passe est haché (jamais lisible) et la base de données est chiffrée au repos. Meuniance ne voit ni ne stocke vos coordonnées bancaires : le paiement d’une formule payante est traité par Stripe.

Qui peut voir vos données

Vous seul, et les personnes à qui vous donnez explicitement accès depuis la page Partage, jusqu’à ce que vous retiriez cet accès. Les règles de sécurité de la base de données empêchent tout autre compte de lire vos lignes.

Notifications

Les notifications de rappel et d’alerte ne contiennent aucun montant.

Durée de conservation

Vos données sont conservées tant que votre compte existe. Après suppression du compte, elles sont effacées de la base ; les sauvegardes techniques éventuelles sont supprimées selon la durée de rétention de notre hébergeur.

Récupérer ou supprimer vos données

« Données › Télécharger mes données » crée un fichier avec tout votre contenu, que vous pouvez restaurer plus tard ; le bouton « Exporter » du tableur donne aussi votre tableur au format Excel. Pour effacer : « Données » permet d’effacer la copie de cet appareil ou de supprimer définitivement votre compte.

Une question sur vos données ?

Écrivez-nous depuis l’adresse e-mail de votre compte. Vous pouvez aussi consulter la politique de confidentialité complète et les conditions d’utilisation.
